# AMON: Asteroid MASCON OCSER N-body

This software was constructed as the main simulation for my thesis entitled DYNAMICS OF A SMALL BODY AROUND ASTEROID (29075) 1950DA, which can be downloaded from the following link:

**Download:** [https://shareok.org/items/980dc813-e5c5-49f2-8b71-2886cede58dd/full](https://shareok.org/items/980dc813-e5c5-49f2-8b71-2886cede58dd/full)

## AMON_main.py contains the main simulation and analysis functions.

*Other software includes:*

  - `Aster_3D_Equil.py`; calculates the 3D equilibrium points using the Newton-Raphson method and the Jacobian and Hessian matrices.
  - `MASCON_Error_Check.py`; contains code comparing the MASCON model to point mass approximation and the direct polyhedron calculations from Tsouli.
  - `Plot_(...).py` or `(...)_Plot.py`; are codes to plot results. This includes
      1. Hyperplane represented
      2. Survival map
      3. Trajectory
      4. Poincaré surface of sections
      5. MASCON Model
**All remaining files are either workspaces (that may be removed later for cleaning) or the MASCON model files themselves.
